OneCalc Android APK banane ke steps
1. github.com par naya repository banaiye (naam: calcora).
2. Is folder ki saari files (hidden .github folder samet) upload kijiye.
3. Repo me Actions tab kholiye -> "Build APK" run hone dijiye (5-8 min).
4. Run poora hone par neeche Artifacts me "OneCalc-APK" download kijiye.
5. Zip khol kar app-debug.apk phone me install kijiye.
